# Dépose tes PDF ici

1. Add file > Upload files, glisse ton PDF dans ce dossier `a-convertir`, puis Commit changes.
2. Onglet **Actions** : attends que le robot passe au vert (2 à 3 minutes).
3. Clique sur le passage du robot : le résumé affiche les valeurs à copier dans Framer.
   Elles sont aussi dans `editions/<nom-du-livre>/infos.txt`.

Le nom du dossier vient du nom du PDF : `Mon Livre 2026.pdf` donne `editions/mon-livre-2026/`.
Renvoyer un PDF du même nom remplace l'ancienne version.

Le PDF peut être exporté en pages ou en planches. La première page devient la couverture,
la dernière le dos, tout le reste les pages intérieures.
